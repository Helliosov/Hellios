# HELLIOS — Software & Automation Portfolio

A responsive, dark-themed portfolio showcasing software projects, services and technical experience.

## Preview

Open `index.html` in a browser. No dependencies or build step.

## Deploy to GitHub Pages

1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select `main`, `/ (root)`, then **Save**.
4. Site address: https://helliosov.github.io/Hellios/
